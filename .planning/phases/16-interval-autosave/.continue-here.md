## 2차 실측에서 규명된 것 (다음 Play 모드 검증에 그대로 쓸 것)
- **Play 모드가 자꾸 멈추는 원인은 [BUG-008](../15-load-timing-and-load-scope/bugs/BUG-008-tutorialboss-animator-missing.md) + Console 의 Error Pause 다.**
  씬 로드 직후 `MissingComponentException` 이 나면 에디터가 자동 일시정지한다(`EditorApplication.isPaused == true`).
  창 포커스나 `runInBackground` 문제가 아니다. Error Pause 를 끄면 해소된다.
- **Unity MCP 보다 Unity CLI 가 검증에 강하다.** MCP 는 `System.Reflection` 을 거부하고 게임 로그를 못 읽지만,
  `unity command eval` 은 리플렉션을 허용하고 `unity command console` 은 런타임 로그를 스택트레이스까지 반환한다.
- **`ScreenSpaceOverlay` UI 캡처**: `unity command capture_game_view --source screen` 이 합성 백버퍼를 잡는다.
  단 일시정지 중에는 직전 프레임이 나오므로 `EditorApplication.Step()` 으로 한 프레임 진행시킨 뒤 캡처해야 한다.
- 긴 대기는 `unity command wait_for --condition '{"member":"UnityEngine.Time.time","op":"greaterThan","value":N}'` 로 건다.
