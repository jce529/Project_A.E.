14-CONTEXT.md 는 이 파일을 "CP949 인코딩"이라 기재했으나, **실측 결과는 그보다 나쁘다.**
계획 단계에서 바이트 단위로 직접 확인한 사실:

| 항목 | 실측값 |
|---|---|
| `file` 판정 | `Unicode text, UTF-8 text, with CRLF line terminators` |

삽입할 블록 (그대로 복사, 문구 변경 금지):
```csharp
    // ---- Keybindings (keybind.json) --------------------------------------------
    // Phase 14 - D-01: file I/O ONLY. InputHandler keeps ownership of the Unity Input
    // System serialization (SaveBindingOverridesAsJson / LoadBindingOverridesFromJson);
    // this class never references InputActionAsset and never parses the payload.
    // D-02: writing a .json file to disk happens in this class and nowhere else in the project.
    // D-04: keybind.json is fully independent from save.json. NewGame(), Save() and the
    // load flow above must never read, write or delete it - key settings survive any
    // game-progress reset and exist with or without a save slot.

    public const string KeybindFileName = "keybind.json";

    public static string KeybindPath
    {
        get { return Path.Combine(Application.persistentDataPath, KeybindFileName); }
    }

    public bool HasKeybindFile()
    {
        return File.Exists(KeybindPath);
    }

    // The payload is already a finished JSON string produced by the Input System, so it is
    // written verbatim - no Newtonsoft round-trip, which would re-encode it into a JSON string literal.
    public void SaveKeybindings(string json)
    {
        if (json == null) json = string.Empty;

        try
        {
            File.WriteAllText(KeybindPath, json);
        }
        catch (System.Exception e)
        {
            Debug.LogError("[SaveLoadManager] Failed to write keybind file: " + e.Message);
        }
    }

    // Returns null when there is no usable keybind file (missing, empty or unreadable).
    // Callers treat null as "keep the defaults baked into the InputActionAsset".
    public string LoadKeybindings()
    {
        if (!HasKeybindFile()) return null;

        try
        {
            string json = File.ReadAllText(KeybindPath);
            return string.IsNullOrEmpty(json) ? null : json;
        }
        catch (System.Exception e)
        {
            Debug.LogError("[SaveLoadManager] Failed to read keybind file: " + e.Message);
            return null;
        }
    }

```
