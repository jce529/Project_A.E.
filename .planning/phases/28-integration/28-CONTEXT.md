## Assumptions
- A1. 노민기 아트는 아직 없다. 컴포넌트와 연결 목록만 만들고 에셋은 만들거나 가정하지 않는다.
- A2. 씬/프리팹은 직접 편집하지 않는다(에디터는 공유 자원). 필요한 연결은 Inspector 연결 목록으로 남긴다.
- A3. 상태 반영 컴포넌트는 플래그 폴링 방식(0.25s)이다. 기믹/상태머신마다 이벤트 시그니처가 달라 공통 이벤트가 없고, 폴링은 기존 클래스를 건드리지 않으며 씬 로드 시 OnEnable 로 저장 상태가 즉시 반영된다.
- A4. 5개 아트 상태 = 기본/작동/비활성/변화/상호작용 → 키 4개(active/disabled/changed/interacted) + 기본(나머지)로 매핑. 우선순위 Disabled > Changed > Interacted > Active > Default.
- A5. 25/26/27 이 합의한 방식(플래그 기록·조회, 이벤트 미사용)이 정본이다. Stage2Events 경로는 선택 경로로 유지(삭제하지 않음).
- A6. Play/컴파일/Unity CLI 검증은 하지 않는다. 정적 점검만. 최종 검증은 사용자가 한꺼번에 한다.
- A7. 병합 순서 23→24→25→26→27, 충돌 없음(자동 병합).
