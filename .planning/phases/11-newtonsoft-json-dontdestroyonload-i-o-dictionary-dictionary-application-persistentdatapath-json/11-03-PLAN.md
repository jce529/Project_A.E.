## 인코딩 경고 (반드시 읽을 것)

이 플랜이 건드리는 5개 파일 중 **2개는 CP949(EUC-KR) 인코딩**이다. UTF-8 로 읽으면 한글 주석이 깨져 보이지만 **파일은 정상**이다. 깨져 보인다고 "고치거나" 다시 저장하면 실제로 파일이 훼손된다.

**규칙:**
1. 삽입하는 모든 코드/주석은 **ASCII 문자만** 사용한다 (5개 파일 전부). 한글 주석을 새로 넣지 않는다.
2. 기존 라인을 **한 줄도 수정/삭제하지 않는다**. Edit 도구의 `old_string` 에는 반드시 **ASCII 만으로 이루어진 앵커 라인**을 쓴다 (아래 각 태스크가 지정). 깨져 보이는 라인을 `old_string` 에 포함시키면 안 된다.
3. 각 태스크 완료 후 `grep -cP "[^\x00-\x7F]" <파일>` 값이 위 표와 정확히 일치하는지 확인한다.
