<interfaces>
From Plan 01-01 (already available):

```csharp
public enum DamageElement { None = 0, Water = 1 }
public struct DamageInfo { public float amount; public DamageElement element; }

public class BossStatsSystem : MonoBehaviour
{
    public void TakeDamage(float amount);              // forwarder (Plan 01-01)
    protected virtual void TakeDamage(DamageInfo info); // protected — NOT callable externally
}
```

**CRITICAL:** External callers cannot invoke the protected DamageInfo overload directly. This plan adds a public wrapper:

```csharp
// Added in Task 1:
public void TakeDamageInfo(DamageInfo info) => TakeDamage(info);
```

This lets WaveSlice, AttackBox, PlayerAttackDamager all call `bossStats.TakeDamageInfo(info)`.
