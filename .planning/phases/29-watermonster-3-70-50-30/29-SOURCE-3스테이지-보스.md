3. 아트팀용 – 모든 패턴 애니메이션 (완전판)
🔥 패턴 1: 물 솟아오르기
전체 흐름
전조 → 집중 → 폭발 → 잔여
1단계 (전조)
● 물이 솟아오를 곳 바닥에 물결 발생 ● 작은 기포 올라옴
2단계 (집중)
● 물이 중심으로 빨려듦 ● 바닥이 움푹 꺼지는 느낌
3단계 (폭발)
푸아아앙!!
● 물 기둥 위로 솟아오름
4단계 (잔여)
● 물이 아래로 떨어짐 ● 바닥 젖음
🔥 패턴 2: 점프 착지
전체 흐름
수축 → 점프 → 정지 → 낙하 → 충격
1단계 (수축)
● 몸이 안쪽으로 말림 ● 물이 안으로 빨려들어감
2단계 (점프)
● 바닥 튕기며 상승
3단계 (공중 정지)
● 잠깐 멈춤 (타이밍 강조)
4단계 (낙하)
쾅!
● 빠르게 낙하
5단계 (충격)
● 바닥 전체 물 튀김 ● 원형 충격파
🔥 패턴 3: 물 확산 폭발
전체 흐름
흡수 → 정지 → 폭발 → 확산
1단계 (흡수)
● 물이 중심으로 빨려듦
2단계 (정지)
● 완전 멈춤
3단계 (폭발)
파아앙!!
● 사방으로 물 튀김
4단계 (확산)
● 바닥에 물 퍼짐
🔥 패턴 4: 물 감옥
전체 흐름
응축 → 발사 → 감금 → 유지
1단계 (응축)
● 코어에서 물 생성 ● 주변에 물 구체가 떠다님
2단계 (발사)
촤아악!!
● 사방으로 직선 발사
3단계 (감금)
● 발사한 물 구체에 닿으면 감금 
-> 크레이지 아케이드 물 감옥 생각하면 편함.
4단계 (유지)
● 표면 출렁임 ● 기포
🔥 패턴 5: 감옥 → 전체 공격
전체 흐름
감옥 → 집중 → 폭발
1단계
● 감옥 유지
2단계 (집중)
● 코어 빛 최대 ● 화면 어두워짐
3단계 (폭발)
콰아아아앙!!!
● 아래에서부터 위쪽으로 맵 전체 타격
🔥 패턴 6: 웅덩이 생성
전체 흐름
생성 → 확산 → 유지
1단계
● 바닥 물이 번짐
2단계
● 웅덩이 형성
🔥 패턴 7: 웅덩이 이동
전체 흐름
붕괴 → 이동 → 재형성
1단계 (붕괴)
● 몸이 아래로 녹음
2단계 (이동)
● 바닥 따라 흐름 (물 속 어두운 그림자 표현 정도면 적당)
3단계 (재형성)
● 다른 웅덩이에서 솟아오름

전체 흐름

● 감옥 형성
