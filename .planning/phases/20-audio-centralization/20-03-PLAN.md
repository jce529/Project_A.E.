[SerializeField] private int poolSize = 16;

// One AudioSource per GameObject: Transform-following playback (D-07) moves a voice's

    public Transform SourceTransform;
    public bool InUse;
    public int Priority;
    public float StartTime;          // unscaled clock time when this voice started
    public Transform FollowTarget;   // null for fixed-position or non-positional playback

Add `AcquireSlot`. These tie-break rules are the concrete resolution of the ambiguity RESEARCH.md flagged in D-08 — implement exactly this:
- A free slot always beats stealing; scan ascending by index, take the first free one.
- If none free, consider only slots whose `Priority` is **strictly less than** the request's priority.
- Among those pick the smallest `StartTime` (oldest).
- On an exact `StartTime` tie keep the earlier index (use strict `<` so a later equal candidate does not displace the incumbent), making the outcome deterministic.
- If nothing qualifies return null; the caller drops the request with no allocation.

```csharp
private PoolSlot AcquireSlot(int requestPriority)
{
    for (int i = 0; i < pool.Length; i++)
        if (!pool[i].InUse) return pool[i];

    PoolSlot steal = null;
    for (int i = 0; i < pool.Length; i++)
    {
        var slot = pool[i];
        if (slot.Priority >= requestPriority) continue;
        // strict '<' keeps the earliest index on a StartTime tie
        if (steal == null || slot.StartTime < steal.StartTime) steal = slot;
    }
    if (steal != null) steal.Source.Stop();
    return steal;   // null => request ignored (D-08)
}
```

Add a single `Update()` that both reclaims finished voices and moves tracking voices. RESEARCH.md prefers this plain polling loop over a coroutine per voice: it is O(16) with zero allocation and matches the project's existing `EnvironmentManager.Update()` style. If Plan 20-02 already added an `Update()`, merge the bodies — do not declare a second one.

```csharp
private void Update()
{
    if (pool == null) return;
    for (int i = 0; i < pool.Length; i++)
    {
        var slot = pool[i];
        if (!slot.InUse) continue;

        if (!slot.Source.isPlaying)
        {
            slot.InUse = false;
            slot.FollowTarget = null;
            slot.Priority = 0;
            continue;
        }

        // D-07: keep a tracking voice glued to its target. A destroyed target (null)
        // freezes the voice at its last position rather than throwing.
        if (slot.FollowTarget != null)
            slot.SourceTransform.position = slot.FollowTarget.position;
    }
}
```

```csharp
// D-07: non-positional playback. Use for UI cues and any 2D SFX.
public void Play(AudioCue cue)
{
    PlayInternal(cue, transform.position, null);
}

// D-07: fixed world-position playback. The voice does not move after it starts.
public void Play(AudioCue cue, Vector3 position)
{
    PlayInternal(cue, position, null);
}

// D-07: tracking playback. AudioManager keeps the voice on target every frame
// (see Update) for as long as the clip plays.
public void Play(AudioCue cue, Transform target)
{
    if (target == null) return;
    PlayInternal(cue, target.position, target);
}

private void PlayInternal(AudioCue cue, Vector3 position, Transform followTarget)
{
    if (cue == null || pool == null) return;

    AudioClip clip = cue.GetClip();
    if (clip == null) return;

    // D-03: ignore a re-request inside the cue's cooldown window. Cooldown 0 always passes.
    float now = Time.unscaledTime;
    if (cue.Cooldown > 0f
        && lastPlayedTime.TryGetValue(cue, out float last)
        && now - last < cue.Cooldown)
    {
        return;
    }

    // D-08: null means every voice is busy at equal-or-higher priority -> drop silently.
    PoolSlot slot = AcquireSlot(cue.Priority);
    if (slot == null) return;

    lastPlayedTime[cue] = now;

    slot.InUse = true;
    slot.Priority = cue.Priority;
    slot.StartTime = now;
    slot.FollowTarget = followTarget;
    slot.SourceTransform.position = position;

    AudioSource src = slot.Source;
    src.clip = clip;
    src.volume = cue.GetVolume();
    src.pitch = cue.GetPitch();
    src.loop = cue.Loop;
    // D-04: fixed per-cue 2D/3D value; no per-cue min/max distance overrides (deferred).
    src.spatialBlend = cue.SpatialBlend;
    // D-09: category decides the mixer group, so the category's volume slider governs it.
    src.outputAudioMixerGroup = GetMixerGroup(cue.Category);
    src.Play();
}
```

Two details that matter:
- Use `Time.unscaledTime` for both the cooldown clock and `StartTime`, so audio pacing and steal ordering behave identically while the game is paused at `Time.timeScale == 0` (the project has a pause menu).
- Write `lastPlayedTime[cue] = now;` only AFTER `AcquireSlot` succeeds, so a dropped request does not start a cooldown for a sound that never played.

Do NOT add any other public API. In particular do not add `Stop`, `StopAll`, fade helpers, or a `PlayBGM(cue)` — none is requested by D-01..D-13 and adding them is scope creep. The BGM `AudioSource` created in Plan 20-02 is separate from this pool and is driven only by `SetEnvironmentState`.
