**2. WaterMonsterStats.cs** — Fix OnDamageTaken not firing (RESEARCH.md Pitfall #2, Integration Note #4):
- The current `TakeDamage(DamageInfo info)` override for non-water calls `base.TakeDamage(info)`, but base only fires `OnDamageTaken` when `IsBarrierActive==true`. Since WaterMonster has `MaxWater=0`, `IsBarrierActive` is always false, so `OnDamageTaken` never fires.
- Fix: After the `base.TakeDamage(info)` call in the non-water path, explicitly invoke `OnDamageTaken?.Invoke()`.
- But `OnDamageTaken` is declared in `BossStatsSystem` as `public event Action OnDamageTaken` -- from a derived class, you cannot invoke a base class event directly in C#. Instead, add a `protected void InvokeOnDamageTaken()` helper method to `BossStatsSystem`:
  ```csharp
  protected void InvokeOnDamageTaken() { OnDamageTaken?.Invoke(); }
  ```
- Then in `WaterMonsterStats.TakeDamage`, after `base.TakeDamage(info)` in the non-water branch, call `InvokeOnDamageTaken()`.
- This ensures that WaterMonsterController's CheckPhase2Trigger subscription will actually receive the event.

**3. WaterMonsterController.cs** — Add Phase 2 trigger (per D-01, D-02, D-03):
- Add fields:
  ```csharp
  [SerializeField] private WeatherController _weatherController;
  [SerializeField] [Range(0f, 1f)] private float _phase2HpThreshold = 0.70f;
  private bool _phase2Triggered = false;
  ```
- Override `Start()`:
  ```csharp
  protected override void Start()
  {
      base.Start();
      if (WaterStats != null)
          WaterStats.OnDamageTaken += CheckPhase2Trigger;
  }
  ```
- Add `CheckPhase2Trigger()` method (matches `Action` signature — no parameters):
  ```csharp
  private void CheckPhase2Trigger()
  {
      if (_phase2Triggered) return;
      if (WaterStats.CurrentHealth / WaterStats.MaxHealth <= _phase2HpThreshold)
      {
          _phase2Triggered = true;
          _weatherController.StartRain();
      }
  }
  ```
- Override `OnDestroy()` (now possible because BossController.OnDestroy is protected virtual):
  ```csharp
  protected override void OnDestroy()
  {
      base.OnDestroy();
      if (WaterStats != null)
          WaterStats.OnDamageTaken -= CheckPhase2Trigger;
  }
  ```
