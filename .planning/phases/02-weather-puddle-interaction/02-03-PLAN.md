  <action>
Create `Assets/Editor/BuildPhase2Assets.cs` with two menu items following the Phase 1 editor script patterns.

**Menu Item 1: `[MenuItem("Tools/Phase2/Build WaterPuddle Prefab")]`**

1. **Register "WaterPuddle" tag** in TagManager.asset:
   - Use `SerializedObject(AssetDatabase.LoadAllAssetsAtPath("ProjectSettings/TagManager.asset")[0])`
   - Find `tags` SerializedProperty, iterate to check if "WaterPuddle" already exists
   - If not, insert at next available index: `tags.InsertArrayElementAtIndex(size)`, set stringValue to "WaterPuddle"
   - Apply modified properties

2. **Create WaterPuddle prefab** at `Assets/Enemy/WaterMonster/Resources/WaterPuddle.prefab`:
   - Create temporary GameObject named "WaterPuddle"
   - Add `SpriteRenderer` component (leave sprite null -- designer sets in inspector)
   - Add `CircleCollider2D` component: set `isTrigger = true`, `radius = 1.5f` (inspector tunable)
   - Add `WaterPuddle` component
   - Set tag to "WaterPuddle"
   - Save as prefab via `PrefabUtility.SaveAsPrefabAsset`
   - Destroy temp object

**Menu Item 2: `[MenuItem("Tools/Phase2/Place Phase2 Objects in Scene")]`**

1. **Create "Phase2_Weather" parent GameObject** in scene root.

2. **Create "RainArea" child** under Phase2_Weather:
   - Add `BoxCollider2D` (isTrigger = true). Set size to (30, 20) as default map coverage (tunable).
   - This BoxCollider2D will be shared by WeatherController and PuddleSpawner.

3. **Create "WeatherController" child** under Phase2_Weather:
   - Add `WeatherController` component
   - Create a child ParticleSystem named "RainParticle" under this object
   - Configure ParticleSystem: emission rate ~50, shape = Box, gravity = 1, start speed = 5, start lifetime = 2, startColor = light blue (0.7f, 0.85f, 1f, 0.6f)
   - Stop the ParticleSystem (so it doesn't play on scene load -- WeatherController.StartRain() will activate it)
   - Wire serialized fields: `rainParticle` = the ParticleSystem, `mapBounds` = RainArea's BoxCollider2D

4. **Create "PuddleSpawner" child** under Phase2_Weather:
   - Add `PuddleSpawner` component
   - Wire: `spawnBounds` = RainArea's BoxCollider2D

5. **Wire WeatherController._puddleSpawner** = the PuddleSpawner component.

6. **Create "PuddlePool" child** under Phase2_Weather:
   - Add `PuddlePool` component
   - Wire: `puddlePrefab` = the WaterPuddle.prefab from Resources folder

7. **Create "PuddleStackManager" child** under Phase2_Weather:
   - Add `PuddleStackManager` component

8. **Wire WaterMonsterController._weatherController**:
   - Find `WaterMonsterController` in scene via `FindObjectOfType<WaterMonsterController>()`
   - Use `SerializedObject` + `FindProperty("_weatherController")` to set reference to WeatherController

9. **Wire PlayerAbsorb on Player**:
   - Find Player GameObject via `GameObject.FindGameObjectWithTag("Player")`
   - If Player doesn't have `PlayerAbsorb`, add it
   - Find `WaterController` on Player (or child) via `FindObjectOfType<WaterController>()`
   - Wire `PlayerAbsorb._waterController` = WaterController reference using SerializedObject

10. **Mark scene dirty** and log success.

All SerializeField wiring must use `SerializedObject` + `FindProperty` + `objectReferenceValue` + `ApplyModifiedProperties()` pattern (private fields are not accessible directly).
