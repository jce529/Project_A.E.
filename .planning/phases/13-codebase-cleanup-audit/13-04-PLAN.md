<encoding_hazard>
이 범위의 CP949(비-UTF-8) 파일은 **26개**다 (프로젝트 전체 46개 중 최다).
정확한 목록은 다음 명령으로 생성한다 (공백 경로 안전):
```bash
find Assets/Script Assets/map Assets/Editor Assets/ImportedAsset -name "*.cs" -type f -print0 \
  | while IFS= read -r -d '' f; do iconv -f UTF-8 -t UTF-8 "$f" >/dev/null 2>&1 || printf '%s\n' "$f"; done | sort
```
반드시 포함되는 것: `Assets/map/script/Checkpoint.cs` (Phase 11 저장 트리거 삽입 시 실제로 인코딩 사고가 났던 파일),
