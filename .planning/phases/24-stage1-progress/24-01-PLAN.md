# Phase 24 Plan 01: 1스테이지 진행 상태 연결

Depends on: Phase 23 (SetGimmick/GetGimmick). 범위: `Assets/map/script/Stage1/*` 신규 스크립트만.

| 작업 | 검증 |
|---|---|
| T1 `Stage1Progress` 정적 상태(키 상수, Get/Set, 순서, CurrentStep, ResetToLower, OnFlagChanged) | 정적 점검: 모든 저장이 Set/GetGimmick 경유, 변경 시에만 이벤트 |
| T2 `Stage1Trigger` 진입 트리거 + requires 순서 보장 | 성공 경로: 선행 키가 없으면 무시, 있으면 플래그 true |
| T3 `Stage1SlideResult` 성공/실패 어댑터 | 실패 시 3개 플래그 해제 + 하층 체크포인트로 RespawnPosition |
| T4 `Stage1ProgressGate` 플래그 기반 오브젝트 토글 | OnEnable에서 저장값 반영 -> 재로드 후 유지 |
| T5 SUMMARY: 키 표 + Inspector 연결 목록 | phase-28 통합이 쓸 수 있음 |

## 기믹 인터페이스 계약
- 이벤트 입력: `Stage1Trigger.Report()`, `Stage1SlideResult.OnSuccess()/OnFail()`, `Stage1Progress.Set(key,true)`.
- 상태 출력: `Stage1Progress.OnFlagChanged(key,value)`, `Stage1Progress.Get(key)`, `CurrentStep()`.

Success Criteria 매핑: (1) 성공 경로 = T2+T3 OnSuccess, (2) 실패 리스폰 = T3 OnFail, (3) 재로드 유지 = SetGimmick 저장 + T4 Apply.
