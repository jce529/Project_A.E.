## 우선순위 제안

1. ~~BUG-001~~: 2026-09-10 해결. `Player.prefab`의 `attackBox` 기본값을 `AttackBox.prefab`에 연결했다. 씬 12개는 동일 값 오버라이드라 무수정.
2. ~~BUG-004~~: 2026-09-10 해결. `Start_B`의 중복 `MainMenuUI`를 제거해 씬에 인스턴스 1건만 남겼다.
3. BUG-002 / BUG-003 → **Phase 15 「로드 시점 및 로드 범위 정의」로 이관**. 두 항목 모두 "로드 시 무엇을 어디까지 복원하는가"에 걸려 있어 개별 수정보다 페이즈에서 함께 확정한다.
4. BUG-003의 보스 프리팹 제작·씬 배치는 Phase 15 범위 밖이며, 규모상 별도 페이즈로 분리한다.
5. ~~BUG-005~~: 2026-09-10 해결. 일시정지 프레임 가드 추가 후 Phase 12 회귀 검증 재수행 완료.

## 공통 완료 기준

- 수정 후 Unity Console 컴파일 오류 0건.
- 관련 씬 또는 프리팹을 저장한 뒤 직렬화 값 재확인.
- 각 문서의 Play 모드 검증 항목을 수행하고 결과와 검증 일자를 기록.
- 해결된 문서의 상태를 `해결됨`으로 바꾸고 수정 커밋을 추가.
