**ChargeRoutine(BossController boss) Coroutine:**

1단계 — Windup (per D-04a):
```
if (!(boss is SpiritController spirit)) yield break;
boss.StopMove();
yield return new WaitForSeconds(spirit.ChargeWindup);
```

2단계 — 목표점 계산 (per D-04b):
```
if (boss.Target == null) yield break;
Vector2 bossPos = boss.transform.position;
Vector2 playerPos = boss.Target.position;
Vector2 dir = (playerPos - bossPos).normalized;
Vector2 targetPos = playerPos + dir * spirit.OvershotDistance;
```
주의: `targetPos` 는 플레이어 위치에서 진행 방향으로 OvershotDistance 만큼 추가된 좌표.
D-04c: 이 목표점은 고정되며 플레이어가 이동해도 변하지 않는다.

3단계 — 돌진 이동 (per D-04a):
```
spirit.SetCharging(true);  // 데미지 1회 플래그 초기화
while (Vector2.Distance(boss.transform.position, targetPos) > 0.3f)
{
    Vector2 moveDir = (targetPos - (Vector2)boss.transform.position).normalized;
    spirit.SetVelocity(moveDir * spirit.ChargeSpeed);
    yield return null;
}
boss.StopMove();
spirit.SetCharging(false);
```

using 문: `using UnityEngine; using System.Collections;`

D-04d 관련: 돌진 중 데미지 적용은 SpiritController.OnTriggerEnter2D 에서 처리됨 (Plan 01). SpiritCharge 는 이동 로직만 담당한다.
