## 파일 구조

### Q4: 3개 슬롯을 디스크에 어떻게 저장할까?

| Option | Description | Selected |
|--------|-------------|----------|
| 슬롯별 별도 파일 (save_0.json/save_1.json/save_2.json) | 기존 save.json 하나를 건드리지 않고 그대로 재사용(슬롯0), 나머지 2개만 신규 파일로 추가. 한 슬롯 저장이 다른 슬롯에 영향 안 줌, 파일 손상 시 하나만 영향받음 | ✓ |
| 하나의 save.json 안에 배열로 동일 파일에 3개 다 담기 | SaveData 리스트 하나를 직렬화. 파일 1개로 관리는 간단하지만, 하나 저장이 전체를 다시 쓰게 되고 파일 손상 시 전체 슬롯이 위험해짐 |  |

**사용자의 선택:** 슬롯별 별도 파일
**Notes:** D-06으로 기록. 정확한 파일명 규칙과 기존 save.json 마이그레이션 방식은 세부 논의 없이
Claude's Discretion(D-07)으로 넘어감 — 연구/계획 단계에서 "기존 세이브 유실 금지"를 절대 기준으로

- 슬롯 카드에 표시할 진행도 내용 — 사용자가 이 영역을 논의 대상에서 제외함. 기본 방향은

  명확해지면 후속 판단.
