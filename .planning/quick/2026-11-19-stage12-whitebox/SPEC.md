## 1. 좌표 변환 기준
- 기존 씬 Grid 셀 = **1.28 월드 유닛**(1스테·2스테 동일). 타일 좌표는 셀 정수, 행 y 는 위가 +.
- 컨셉 이미지 맵 가로 전체(≈1228px, 확대 250% 화면 기준) = **368칸** → **1px = 0.30칸**. 가로·세로 모두 같은 비율.
- 가로 원점: 기존 `1 stage start`/`2 stage start`(월드 127.39, -15.27 → 셀 99, -12) = 이미지 START. 바닥 최상단 행 -13(표면 y=-12).
- 오른쪽 끝(셀 ≈467)은 기존 보스 카메라 트리거(월드 592 → 셀 462)와 일치시켰다. 보스 트리거는 옮기지 않는다.
- 플레이어 수치(씬 Player): jumpPower 20, gravityScale 5(g=49.05), 점프 최고 높이 ≈ 4.08u = **3.2칸**, 체공 0.82초, 달리기 7 → 최대 도약 ≈ **4.5칸**, 기본속도 3 → 1.9칸, 대시 20×0.15 = 3u(2.3칸).

## 5. 가정(이미지로 확정 불가 → 합리적 기본값)
1. 컨셉 이미지는 일러스트라 정확한 치수가 없다. 모든 높이·폭은 1px=0.30칸 환산 후 점프 한계(3.2칸/4.5칸)에 맞춰 3행 단차와 3칸 간격으로 보정했다.
2. 슬라이드(곡선)는 계단형 지형으로 대체했다(실제 슬라이드 물 효과는 `MapProgress_*` 오브젝트가 담당).
3. 2-1 고목 내부 공간, 2-2 4·5·6번 사이 세부 길(PDF는 물길 방향 변경 기믹)은 층 바닥과 사다리 수준으로만 표현했다. 6번 탐색 구간·5번 레버 위치는 정렬 단계(맵 진행 오브젝트)에서 맞춘다.
4. 2-2 의 4 상층 진입~6 탐색 사이 층간 이동은 사다리 2개만 둔다(PDF 화살표로는 3개 이상이나 위치가 불확실).
5. 두 스테이지 모두 기존 `Surface` 타일(아트)은 전부 지우고 흰 타일로 다시 칠한다(원본은 `backup/`).
6. 1스테·2스테 씬의 Player 시작 위치와 `*stage start` 는 이미 (127,-15) 이므로 이동하지 않는다. 기존 오브젝트(Tutorial Boss, fallzone, Check Group 등)는 위치 그대로이며 새 맵과 어긋날 수 있다(정렬 단계에서만 `MapProgress_*` 프리팹 위치 조정 검토).
